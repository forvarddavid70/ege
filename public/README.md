# Статические файлы (`public/`)

Файлы из этой папки отдаются с корня сайта. Например, `public/tutor.jpg`
доступен по адресу `/tutor.jpg`.

## Фото репетитора (аватар)

Аватар репетитора берётся из настройки `avatarUrl` (по умолчанию `/tutor.jpg`).

Чтобы добавить своё фото, есть три способа:

1. **Загрузка PNG из админки (рекомендуется).** Откройте скрытую админку
   `/enter` → «Настройки» → блок **«Фото/аватар репетитора»** →
   **«Загрузить PNG»**. Файл сохранится в `public/uploads/` и сразу подставится
   в поле — никаких ссылок вручную вводить не нужно.
2. **Файл в проект.** Положите изображение сюда как `public/tutor.jpg`
   (квадратное, желательно от 512×512, `.jpg`/`.png`/`.webp`).
3. **Внешний URL.** В том же поле можно вставить прямую ссылку на картинку.

Пока фото не задано (или файл не найден), сайт аккуратно показывает
брендовый кружок с инициалами — «битой» картинки не будет.

## Изображения раздела «О себе»

В админке `/enter` → «Настройки» → **«Изображения раздела „О себе“»** можно
**загрузить PNG-файлы** (рекомендуемый размер — **800×600 px**, соотношение 4:3,
до 8 штук). Они появляются галереей в разделе «Обо мне». Загруженные
файлы хранятся в `public/uploads/` и не попадают в git (см. `.gitignore`).
