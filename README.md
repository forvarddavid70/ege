# ЕГЭ Father — сайт репетитора по химии (Никита Понасенков)

Одностраничный сайт (лендинг) для репетитора по химии **Никиты Понасенкова** под брендом
**«ЕГЭ Father»**: подготовка к ЕГЭ, форматы занятий, результаты учеников, разбор заданий ЕГЭ, блог
и **отзывы клиентов**. Клиент связывается с репетитором через **Telegram** или через
**форму заявки** на сайте (заявка приходит владельцу в Telegram через бота). Для автора есть
**скрытая, неиндексируемая админка** по адресу `/enter`, где можно редактировать разделы
**Блог/новости**, **Курсы**, **Задания ЕГЭ** и **Отзывы**, а также контакты и тексты
(в том числе бренд, слоган и ссылку на канал). Есть страница
**политики конфиденциальности** (`/privacy`) и **баннер согласия на cookie**.

**Дизайн:** тёмная тема в приглушённой палитре — чёрный / серый / спокойный
приглушённый фиолетовый (без кричащего неона, свечений и тяжёлых карточек‑блоков),
кастомные SVG‑элементы на химическую тематику (молекулы, бензольные кольца, колбы, атомы,
гексагональный фон), выдержанные в **насыщенной фиолетово‑фуксиевой градиентной**
палитре (кнопки, кольца аватаров, крупные акценты). Фотографии — аватар репетитора
и галерея раздела «О себе» (см. ниже); остальной контент — текст и SVG.

**Фото/аватар репетитора.** В шапке hero и в разделе «Обо мне» показывается
аватар репетитора. Он берётся из настройки `avatarUrl` (по умолчанию `/tutor.jpg`).
Проще всего **загрузить PNG прямо из админки** `/enter` → «Настройки» →
«Загрузить PNG» (файл сохранится в `public/uploads/`); также можно положить файл в
`public/tutor.jpg` или указать внешний URL. Пока фото не задано, показывается
брендовый кружок с инициалами — «битой» картинки не будет (см. `public/README.md`).

**Изображения раздела «О себе».** В админке `/enter` → «Настройки» →
«Изображения раздела „О себе“» можно **загрузить PNG‑файлы** (рекомендуемый размер
**800×600 px**, до 8 штук) — они выводятся галереей в разделе «Обо мне».
Хранятся в настройке `aboutImages` и в `public/uploads/` (в git не попадают).

Стек: **Next.js 14 (App Router) + TypeScript + Tailwind CSS**. Контент хранится в
JSON‑файлах и редактируется прямо из админки (без внешней базы данных).

## Быстрый старт

```bash
npm install
cp .env.example .env.local   # заполните ADMIN_PASSWORD, AUTH_SECRET, Telegram-логин
npm run dev                  # http://localhost:3000
```

Прод:

```bash
npm run build
npm run start
```

### Переменные окружения (`.env.local`)

| Переменная | Назначение |
| --- | --- |
| `ADMIN_PASSWORD` | Пароль для входа в админку `/enter` |
| `AUTH_SECRET` | Секрет для подписи сессионной cookie (`openssl rand -hex 32`) |
| `NEXT_PUBLIC_TELEGRAM_USERNAME` | Запасной Telegram‑логин, если не задан в админке |
| `NEXT_PUBLIC_SITE_URL` | Запасной канонический адрес сайта для SEO (sitemap, Open Graph, JSON‑LD), если не задан в админке. Напр. `https://egefather.ru` |
| `TELEGRAM_BOT_TOKEN` | Токен бота от `@BotFather` — для отправки заявок из формы |
| `TELEGRAM_CHAT_ID` | ID чата/пользователя, куда бот присылает заявки |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS` | SMTP для **автоответа клиенту** на e‑mail (необязательно) |
| `SMTP_SECURE`, `SMTP_FROM` | `true` для SSL (порт 465) и адрес отправителя автоответа (необязательно) |

Без `ADMIN_PASSWORD` вход в админку невозможен (логин вернёт ошибку). Без
`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` форма заявки вернёт понятную ошибку и
предложит написать в Telegram напрямую (остальной сайт работает как обычно).

## Разделы лендинга

- **Hero** — бренд «ЕГЭ Father», имя репетитора, слоган («Скажешь спасибо через полгода»),
  темы Telegram‑канала и ключевые цифры. Справа — карточка‑портрет репетитора с
  аватаром, ролью и слоганом (на мобильных — компактная «шапка профиля» сверху).
- **Результаты** — средний балл, доля 90+, вузы поступления и мини‑кейсы «было → стало».
- **Как учимся** — план подготовки из 6 шагов.
- **Форматы занятий** — карточки форматов занятий с записью в Telegram (текст подставляется автоматически).
- **Задания ЕГЭ** — раскрывающиеся карточки с условием, решением и ответом.
- **Блог** — записи с кастомными SVG‑обложками (вместо фото) и ссылкой на канал.
- **Отзывы** — карточки отзывов учеников и родителей со звёздным рейтингом, автором,
  результатом‑бейджем и сводной средней оценкой; редактируются в админке.
- **Обо мне + контакт** — аватар и текст о репетиторе и CTA на бесплатное пробное занятие.
- **Оставить заявку** — форма (имя, телефон, e‑mail, ник в Telegram, ник во ВКонтакте,
  сообщение + согласие на обработку ПД). Заявка уходит владельцу в Telegram через бота;
  есть honeypot и rate‑limit против спама.
- **Футер** — копирайт, ссылка на политику конфиденциальности и подпись
  «Powered by team of connect.trioz.ru».

Секции появляются с плавной анимацией при прокрутке (scroll reveal), а во время загрузки
показываются **скелетоны**‑заглушки. Всё уважает системную настройку «уменьшить движение».

## Скрытая админка `/enter`

- Открывается по прямой ссылке `/(домен)/enter` — ссылок на неё на сайте нет.
- **Не индексируется**: `robots.txt` (`Disallow: /enter`), мета‑тег `noindex,nofollow`
  и заголовок `X-Robots-Tag: noindex, nofollow` на `/enter/*` и `/api/*`.
- Вход по паролю; сессия — подписанная `httpOnly`‑cookie на 12 часов.
- Разделы: **Настройки** (имя, бренд, фото/аватар, слоган, тексты, контакты, Telegram‑логин,
  канал и текст сообщения, **адрес сайта для SEO**, **счётчики Яндекс.Метрики и Google Tag
  Manager**, **токен подтверждения Google Search Console**), **Заявки**, **Блог/новости**,
  **Курсы**, **Задания ЕГЭ**, **Отзывы**. В разделах
  контента можно добавлять, редактировать и удалять записи, затем нажать «Сохранить».
- **Заявки** — список заявок, оставленных через форму на сайте: контакты, сообщение, дата,
  фильтр по статусу (Новая / В работе / Обработана), смена статуса и удаление. Отметка
  «автоответ отправлен» показывает, ушло ли клиенту письмо‑подтверждение.

> Изменения сохраняются в `data/<раздел>.local.json`. Эти файлы не попадают в git
> (см. `.gitignore`), поэтому правки автора не перетирают исходный контент репозитория.
> Настройки при чтении мержатся с дефолтами, поэтому старые `settings.local.json`
> без новых полей (бренд, слоган, канал) не ломают сайт.

### Хранение контента и деплой

Правки пишутся на диск сервера. Это отлично работает на **VPS / в Docker‑контейнере с
постоянным томом**. На платформах с «эфемерной» файловой системой (например, обычный
serverless без volume) изменения не сохранятся между перезапусками — там нужен том или
переход на внешнее хранилище (см. раздел «Идеи по развитию»).

## Интеграция с Telegram

Реализованы два способа связи:

- **Deep‑link в личку.** Кнопки «Написать/Записаться в Telegram» и плавающая кнопка ведут
  на `https://t.me/<логин>?text=<предзаполненный текст>`. У кнопки «Бесплатное пробное
  занятие» и карточек курсов текст сообщения подставляется автоматически (с именем
  репетитора и названием курса).
- **Форма заявки → сохранение + уведомление боту + автоответ.** Клиент оставляет заявку прямо
  на странице; сервер (`POST /api/lead`) **сохраняет её** (появляется в админке `/enter` →
  «Заявки»), отправляет владельцу в Telegram через Bot API (`sendMessage`, `TELEGRAM_BOT_TOKEN`
  и `TELEGRAM_CHAT_ID`) и, если клиент указал e‑mail и настроен SMTP, шлёт клиенту
  **автоответ‑подтверждение**. Заявка сохраняется даже без Telegram/SMTP, поэтому ничего не
  теряется. Токен, chat id и SMTP‑данные — только на сервере. Есть защита от спама: скрытое
  honeypot‑поле и rate‑limit по IP.

Ссылка на **Telegram‑канал** (кнопка «Читать канал» в блоге), логин и текст по умолчанию
настраиваются в админке без правки кода.

### Как настроить бота для заявок

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите `TELEGRAM_BOT_TOKEN`.
2. Напишите боту (или добавьте его в нужную группу/канал), затем узнайте `TELEGRAM_CHAT_ID`
   (например, у [@userinfobot](https://t.me/userinfobot); для группы/канала id обычно
   начинается с `-100...`).
3. Впишите обе переменные в `.env.local` и перезапустите сервер.

### Варианты интеграции на будущее

1. **Telegram‑бот + приветствие.** Клиент попадает к боту, который сразу отвечает,
   собирает класс/цель/удобное время и присылает репетитору лид. Нужен бот у @BotFather.
2. **Telegram Login Widget / чат‑виджет.** Для авторизации или встроенного чата.

## SEO, микроразметка и аналитика

- **`sitemap.xml` и `robots.txt`** генерируются автоматически (`app/sitemap.ts`, `app/robots.ts`).
  `robots.txt` закрывает `/enter` и `/api`, указывает `Host` и ссылку на карту сайта. Адрес
  сайта берётся из настройки **«Адрес сайта для SEO»** в админке, иначе из `NEXT_PUBLIC_SITE_URL`.
- **Open Graph / Twitter.** В `app/layout.tsx` заданы `metadataBase`, теги Open Graph и
  `summary_large_image` для Twitter. Карточка‑превью — `public/og.png` (1200×630, фирменный
  фиолетово‑фуксиевый дизайн).
- **Микроразметка schema.org (JSON‑LD).** На главной странице выводится граф из `WebSite`,
  `Person` (репетитор: специализация, контакты, соцсети) и `Course` (каждый курс со ссылкой на
  репетитора как провайдера) — см. `components/StructuredData.tsx`.
- **Аналитика.** В админке задаются счётчик **Яндекс.Метрики** (с webvisor и картой кликов) и
  контейнер **Google Tag Manager** (внутри которого настраивается GA4 и прочие теги). Скрипты
  (`components/Analytics.tsx`) подключаются на публичных страницах **только после согласия**
  пользователя в баннере cookie; в служебном разделе `/enter` аналитика не грузится.
- **Подтверждение прав в Google Search Console.** Токен из настройки
  «Google Search Console — токен подтверждения» выводится мета-тегом `google-site-verification`
  в `<head>` через метаданные `app/layout.tsx`. Это не cookie и не трекинг, поэтому тег
  присутствует всегда, независимо от согласия на cookie.

## Политика конфиденциальности и cookie

- Страница `/privacy` — политика обработки персональных данных (по 152‑ФЗ) и сведения об
  использовании cookie. Тексты берут бренд и контакты из настроек; реквизиты оператора
  (ФИО/ИНН/адрес) заполняются владельцем.
- Ссылка на политику есть в футере и рядом с чекбоксом согласия в форме заявки.
- **Баннер согласия на cookie** (`components/CookieConsent.tsx`) показывается один раз;
  выбор сохраняется в `localStorage`. Сайт использует только строго необходимые
  (технические) cookie — в частности, сессию админки.

## Идеи по улучшению

- **Доверие и конверсия:** видео‑визитка, гарантия первого пробного занятия (отзывы уже есть).
- **Заявки:** интеграция с CRM, экспорт в CSV, напоминания по необработанным заявкам.
- **Аналитика:** цели по кликам в Telegram и отправкам формы.
- **Контент ЕГЭ:** фильтр заданий по номеру/теме/сложности, поиск, теги, формулы (KaTeX).
- **Надёжность контента:** при росте объёма — перенос из JSON в БД (SQLite/Postgres + Prisma).
- **Безопасность админки:** ограничение попыток входа (rate‑limit), журнал входов.

> Реализовано в этом обновлении: SEO (`sitemap.xml`, Open Graph‑картинка, микроразметка
> `Person`/`Course`), автоответ клиенту и раздел «Заявки» в админке, аналитика
> (Яндекс.Метрика + Google Tag Manager) с настройкой из админки.

## Заметка о безопасности

Пароль и секрет сессии берутся только из переменных окружения и никогда не попадают на
клиент. API‑маршруты изменения контента доступны исключительно после входа. Не
коммитьте `.env.local` в репозиторий.

## Выдача заданий

В `/enter` раздел **«Выдача заданий»** использует фиксированную двухуровневую структуру: корневая папка — проект, подпапки — подтипы (классификации) заданий. Третий уровень не создаётся. Задания добавляются только внутрь подтипов.

Для проекта создаётся одна постоянная ссылка `/assignment/<slug>`. Повторное нажатие показывает и копирует ту же ссылку, а изменения неопубликованной работы обновляют содержимое без смены адреса. После отправки учеником работа фиксируется для проверки. Итоговая вертикальная диаграмма содержит ровно по одному цветному столбцу на каждый подтип проекта.

Уведомления используют `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`; результаты и структура хранятся в `data/assignments.local.json`. Каждое задание может содержать изображение PNG, JPEG или WebP до 5 МБ; оно показывается ученику сразу в развёрнутом виде и включается в проверочный PDF.
